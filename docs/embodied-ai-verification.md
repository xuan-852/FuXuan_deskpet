## 一、背景

### 现状

```
MotionPlanner.PlanFromDescription():
  ├─ 硬编码模板 (10种): 挥手 / 点头 / 摇头 / 鞠躬 / 伸懒腰 / 叉腰 / 捂脸 / 指 / 招手 / 合十
  └─ 回退 → MotionTranslator.TranslateAsync() 拦截 → DeepSeek API 生成结构化关键帧

MotionTranslator 内部:
  10 条通用规则 + 10 种 SPECIAL PATTERNS（9 姿势，捂脸重复）+ VERIFIED FEEDBACK
```

> ⚠️ 代码核对：`KNOW_PATTERNS` 实际为 10 条（9 个独特姿势 + 捂脸出现两次），非旧文档所称 12 种。

### 核心验证问题

> "AI 是真的理解动作描述并生成了合理的参数序列，还是只是随机生成了一些看起来「有变化」的参数组合？"

### 验证标准

| 等级 | 定义 | 判定方法 |
|------|------|---------|
| PASS ✨ | 动作可被肉眼识别且符合语义 | 人类观察 + GLM-4V 2×2 拼图 |
| PASS ✅ | 参数序列物理合理 | 自动校验（范围/对称/平滑） |
| FAIL ❌ | 越界/抖动/不符合语义 | 自动校验 |

## 三、验证工具

### 3.1 MotionVerifier.cs

功能：
1. 逐条执行测试集
2. 记录：LLM 路径 / 关键帧数 / 时长 / 参数集
3. 自动校验：范围 / 对称对 / 无意义抖动 / 归零
4. 输出结构化报告

> ⚠️ 注意：早期文档提到写入 `validation_log.json`，但 `D:\DesktopPetData\` 下并无此文件（代码未实现持久化到该文件名），实际报告经 `Debug.Log` 输出。

接口：
- `RunVerificationSuite()` → 完整报告
- `RunSingleTest(string)` → 单条结果
- `CompareMotionPlans(a, b)` → 相似度对比

### 3.2 GLM-4V 交叉验证

```
触发动作 → 截图 (20/40/60/80%)
  → 合成 2×2 拼图
  → GLM-4V: "评估此动作与「{描述}」是否一致，1-5分"
  → 评分 + 写入 MotionMemory
```

### 3.3 SafetyValidator 自动校验

| 校验类型 | 规则 |
|---------|------|
| 互斥组 | 睁大眼 vs 眯眼 不同时激活 |
| 对称对 | ParamBrowRY/LY 同时出现 |
| 极端值 | ParamAngleX/Y/Z 不越界 (±30) |
| 归零 | 结束帧参数归零或近零 |

## 六、关键优化历程

### N34 (2026-07-07) — SPECIAL PATTERNS 优化

基于 vis_verify 基线发现问题：

| 动作 | 问题 | 修复 |
|------|------|------|
| 捂脸 | arm_mid 不够高 | 升至面部区域 |
| 捂嘴 | 无嘴部约束 | 新增 ONE_HAND + mouth_open_y=0 |
| 叉腰 | arm_lower 幅度不足 | 0.15→≥0.4 |
| 缩团 | 无弓身 | body_angle_y 前倾 |
| 行礼 | 体轴错误 | body_angle_x → body_angle_y |

### VERIFIED FEEDBACK 机制

每次 DeepSeek 翻译调用时，在 system prompt 注入：
- 上次成功的动作案例（从 MotionMemory 取高分 TOP-3）
- 上次失败的案例及原因（从 MotionMemory 取反例 TOP-3）

### 盲探索

GLM-4V 描述当前姿态 → 发现模型能做到但从未尝试过的动作组合 → 补充到 KNOW_PATTERNS

1. 打开 Unity 编辑器，启动场景
2. 打开控制台 (Ctrl+Shift+C)
3. 在聊天输入框输入:
   - `"害羞地捂脸"` → 观察自动播互动
   - `\verify` → 运行完整验证套件
4. 或通过代码:

```csharp
// 在任意协程中：
var verifier = new MotionVerifier();
string report = verifier.RunVerificationSuite(renderer.Mapper, renderer.CubismModel);
Debug.Log(report);
```

### 在右键菜单中添加验证按钮（可选）

ContextMenu 新增「🧪 具身验证」按钮 → 一键运行 T1~T10
