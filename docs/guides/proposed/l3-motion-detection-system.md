# L3 动作检测与语义评审体系（提案）

> **状态**：提案（`proposed`），未经批准不得实施。
>
> **上位决策**：[产品方向基线](../decisions/2026-09-15-product-direction-baseline.md) §4、[L3 认证指导](approved/l3-embodied-skill-certification.md)、[探评测准确性指导](approved/probe-evaluation-accuracy.md)。
>
> **实证基础**：[动作评审条带试点](../truth/l3-motion-review-strip-pilot.md)（五模型同卷、描述变体实验、控制样本方法论，2026-09-18）。

## 1. 目标与非目标

**FR-L3-06**：为动作库扩充建立可持续的动作质量检测流水线，使每个候选动作从取证到入库的人工成本趋近于零，且判定结果对评审模型选择不敏感。

**FR-L3-07**：以数学化的漂移检测与硬约束防止动作质量迭代退化（如幅度夸张化），人工只保留"一次性定义偏好"与"审计被标记异常"。

非目标：不改变已认证技能的既有认证结论；不覆盖多动作组合与叠加表情的检测（另行立项）；不让任何单一模型裁决动作质量；不取消认证流程的人工签字环节。

## 2. 分层裁决架构

> 依据：五模型同卷实测没有任何单一模型能三样本全对；分层架构对模型选择不敏感。

```text
候选动作（自带期望轨迹签名 + V3风格语义边界）
  ▼
L1 本地机械取证（确定性，一票否决，零成本）
  实测像素差时间线 vs 期望轨迹签名相关性；幅度可见性(LPIPS)；复位差
  ✗ 不过 → 拒绝，不进云端
  ▼
L2 证据生成
  按参数速度非均匀采样条带（捕捉眨眼等快事件）+ 差异热图
  每批强制携带静止对照 + 乱序对照（控制样本）
  ▼
L3 盲语义评审（模型只答"像什么"，不裁决"有没有动"）
  Qwen3-VL-plus 主判（盲描述，空响应重试）→ 纯文本边界比对
  GLM-4.6V 文本复核；分歧交 Gemini 终审抽查 → 仍不确定 → 人工看帧
  ▼
L4 人工签字 → 入库（同时沉淀为金样本）→ 路由表/行为层扩条目
  ▼
运行时抽检（每天限次）：低分只标记，人工审计后处理，禁止自动降频
```

各层真值性质：执行层真值=参数曲线（发行方自证）；呈现层真值=本地像素指标（确定性）；语义层无客观真值，语义边界是产品定义，评审检验"呈现能否被识别为该定义"；自然度最终裁判是人。

## 3. 数学工具与开源选型

| 层 | 数学原理 | 选型 | 说明 |
|---|---|---|---|
| L1 轨迹验证 | 激励-响应相关（皮尔逊/DTW） | 本地实现 | 实测像素差时间线对照期望签名，多峰摇摆不误判为乱动 |
| L1 可见性 | 感知相似度 | `lpips` / `pytorch-msssim`（开源，本地） | 替代原始 RGB 差，量化保守幅度的人眼可见性 |
| L3 评审员校准 | 信号检测论 d′/β | 本地实现 | 每批控制样本自动计算，d′ 低于阈值当批作废 |
| 漂移检测 | 马氏距离 / MMD 两样本检验 | `alibi-detect` / `evidently`（开源） | 库小（<30 动作）时先用逐特征分位数边界，再升级协方差 |
| 防夸张 | 合同式约束 | 能力普查已验证范围做硬钳位 | 夸张在构造期被禁止，而非靠评审拒绝 |

明确不采用：FVD（需大参考集）、R-Precision/FGD（3D 骨架体系，Live2D 不适用）。

## 4. 硬约束

- **C-L3-08 控制样本强制**：任何评审批次必须携带已知答案的静止/乱序对照；对照判错则该评审员当批结果全部作废（AC-ACC-02 常态化）。
- **C-L3-09 边界书写标准**：语义边界必须含①明确方向 ②可观察后果（衣物摆动等）③排除项；禁止"保守幅度"类不可校准措辞。边界版本化，改边界须重审。
- **C-L3-10 轨迹由本地裁决**：任何模型不得裁决动作存在性/轨迹/复位；本地判定非连贯时模型结果不予采信。
- **C-L3-11 运行时抽检限额**：每天评审次数设上限；低分动作只标记待人工审计，禁止自动降频（防评审偏好污染反馈回路）。
- **C-L3-12 成本与许可**：单动作全流程云端成本 ≤0.1 元、每批 ≤6 元（沿用默认阈值）；模型帧外发沿用逐批用户授权协议；API Key 只经环境变量，不入库。
- **C-L3-13 金样本沉淀**：每次人工签字（含既有 7+1 动作的补签）记录为可复用校准数据；评审方案变更须通过金样本一致率回归。

## 5. 已知债务与迁移项

1. 身体技能关键词映射硬编码于 `LocalToolRouter`，扩库时须迁移为技能定义自带关键词的数据驱动形式；
2. 旧 `IdleActionScheduler` 写参数不经协调器（C-L3-01 既有债务），行为层当前叠加其上，需独立任务包收编；
3. 漂移检测在动作库 <30 时仅用分位数边界；
4. 描述变体实验样本量 n=1，V3 标准随每批控制样本持续验证。

## 6. 验收

| ID | 证据 | 通过标准 |
|---|---|---|
| AC-L3-07 | 三样本基准（正/乱序/静止）回归脚本 | 当前选定评审组合全部判对；控制样本判错可自动检出 |
| AC-L3-08 | 流水线端到端试点（1 个真实新候选） | L1 拒绝率、L3 判定、成本记录齐全；人工只出现在签字与审计 |
| AC-L3-09 | 金样本一致率记录 | 评审组合与人工判定一致率 ≥ 阈值（首版阈值由人工签字后确定） |
| AC-L3-10 | 漂移检测报告 | 参考分布建立；注入夸张样本可被自动标记 |

## 7. 实施授权边界

- **未来允许范围**：条带生成与本地指标实现、评审脚本与供应商接入、期望签名与漂移检测、金样本问卷与记录、直接文档与任务包。
- **禁止范围**：取消人工签字、自动降频或淘汰、跳过控制样本、把语义边界改为模型生成不经人工确认、运行时高频云端评审、Key 入库。
- **阻断条件**：评审成本超预算、金样本一致率持续不达标且无修正手段、许可或隐私边界变化 → `BlockedByDecision`。
