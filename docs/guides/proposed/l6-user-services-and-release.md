# L6 办公、知识、提醒与发布指导文档

> **状态**：提案，禁止下发实现任务。
>
> **上位决策**：[产品方向基线 §7](../../decisions/2026-09-15-product-direction-baseline.md#7-l6办公知识提醒安装与发布)。

## 目标与约束

非目标：不静默更新、不自动打开生成文件、不让外部网页直接触发工具或记忆写入。

- **FR-L6-01**：办公文件生成到专用 Documents 目录；生成前明确路径/类型，完成后由用户决定打开；绝不覆盖同名文件。
- **FR-L6-02**：知识仅处理用户提供内容或用户开启的联网检索；展示来源与时间；外部文本不可信、不自动入长期记忆且不能触发工具。
- **FR-L6-03**：提醒本地存储，以气泡和可选通知低打扰提示；完成/关闭/稍后可追踪，逾期有限重试。
- **FR-L6-04**：更新不静默安装；展示来源/说明，用户确认后执行；更新前备份数据，失败可回退。
- **C-L6-01**：安装器、依赖与更新必须验证签名/来源；Token 不复用、不写日志；不得回退到机器 PATH Node。

## 验收与待决项

| AC | 证据 | 标准 |
|---|---|---|
| AC-L6-01 | 隔离生成测试 | 无覆盖，路径/类型正确，未自动打开 |
| AC-L6-02 | 来源/注入测试 | 可追溯、无外部指令执行或记忆污染 |
| AC-L6-03 | 提醒时序测试 | 有限重试、不抢焦点 |
| AC-L6-04 | 更新失败演练 | 用户确认、备份有效、可回退 |

待决：提醒逾期次数/间隔、联网检索的默认开关与更新渠道。涉及新权限、安装器执行或数据迁移一律 `BlockedByDecision`。

## 实施授权边界

允许专用输出、来源展示、提醒与更新确认链路；禁止覆盖用户文件、绕过签名校验或静默安装。
