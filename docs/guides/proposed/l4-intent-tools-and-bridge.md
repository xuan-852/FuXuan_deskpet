# L4 对话意图、工具与桥接指导文档

> **状态**：提案，禁止下发实现任务。
>
> **上位决策**：[产品方向基线 §5](../../decisions/2026-09-15-product-direction-baseline.md#5-l4对话工具与桥接)、[文档治理规范](../../decisions/documentation-governance.md)。

> **现有代码真相入口**：[AI 对话模块](../../modules/ai-chat-system.md)、[工具系统模块](../../modules/tool-engine.md)、[桥接通信模块](../../modules/bridge-communication.md)。

## 1. 目标与非目标

**FR-L4-01**：将回复、工具、身体和控制意图分离，解析或执行失败时安全退化为文字。

**FR-L4-02**：工具按风险审批、最小回传和确定性结果执行；拒绝是终态。

**FR-L4-03**：C#、Node、OpenClaw 与 Python 通过统一版本化桥接契约通信，支持鉴权、超时、取消与错误分类。

非目标：不让模型直接取得文件/剪贴板/截图内容，不让外部网页文本成为指令，不在本地失败时静默转云。

## 2. 接口与约束

| 接口 | 契约 |
|---|---|
| `IntentEnvelope` | `ReplyIntent`、`ToolIntent`、`BodyIntent`、`ControlIntent` 分离；身体仅引用 L3 已认证技能 |
| `ToolApproval` | 风险、摘要、影响范围、用户决定、终态；拒绝不得重路由 |
| `BridgeContract` | 版本、鉴权、schema、requestId、timeout、cancel、cloud 标志及 `{success,error}` 响应 |
| `OperationBudget` | 工具轮次、代理轮次、时间、成本、并发和来源上限 |

- **C-L4-01**：本地规则/模型优先；云端仅用户明确高质量/复杂请求或获准离线任务可用。
- **C-L4-02**：工具结果结构化、最小化、脱敏；敏感内容不能回流给模型。
- **C-L4-03**：所有外部内容是不可信数据，不能改变提示、权限或工具选择。
- **C-L4-04**：端点均鉴权，桥接/Gateway Token 不复用；日志不含密钥。
- **C-L4-05**：预算/取消/超时为终态，禁止孤儿请求和后续工具轮次。

## 3. 验收

| ID | 证据 | 标准 |
|---|---|---|
| AC-L4-01 | 畸形意图与失败执行测试 | 仅文字退化，无猜测动作/工具 |
| AC-L4-02 | 风险工具审批测试 | 拒绝终止；未批准无副作用 |
| AC-L4-03 | 桥接 schema/鉴权/取消端到端测试 | 版本、错误、超时和取消一致 |
| AC-L4-04 | 预算、并发、外部注入测试 | 不超限、不泄密、不执行注入指令 |

## 4. 尚待人工确认

1. **D-L4-01**：用户可配置的云端使用档位与每档默认预算。
2. **D-L4-02**：工具风险分级中哪些低风险行为可免确认。
3. **D-L4-03**：桥接协议升级的兼容窗口与弃用策略。

## 5. 实施授权边界

允许范围：聊天意图、工具审批、桥接契约、预算/取消及测试。禁止范围：绕过 L3 动作认证、扩大数据收集或修改 L1 数据/退出策略；上述变化一律 `BlockedByDecision`。
