## 1. 目标与非目标

**FR-L2-01**：桌宠在主屏上拥有稳定、可解释的桌面位置、重力、拖拽、抛掷、落地与地面移动行为。

**FR-L2-02**：透明桌面窗口不阻碍普通桌面操作；可见模型和 UI 在用户直接交互时可靠接收输入。

**FR-L2-03**：模型可见位移必须与已认证步行表现同步，避免滑行、反向行走、缩放穿零翻面或拖拽后失控。

**FR-L2-04**：分辨率、DPI、任务栏/工作区变化后，模型比例、命中区、活动范围与恢复位置保持合理。

非目标：当前不实现跨显示器自由移动，不读取其他应用窗口以做碰撞，不用 LLM 直接控制每帧位移或 Live2D 参数，不承诺未经 L3 认证的新步态。

## 2. 分层与公开接口契约

| 层/接口 | 职责 | 不得承担 |
|---|---|---|
| `DisplayLayout` | 主屏工作区、DPI、模型尺寸、命中/窗口边界、地面线与活动区 | 行为决策、Live2D 参数写入 |
| `PhysicsRoot` | 位置、速度、重力、边界、地面、拖拽与抛掷 | 自主散步意图、面部/肢体动作 |
| `BehaviorRoot` | 地面目标、局部回应、受控随机散步、朝向请求 | 直接跨越物理边界、直接修改窗口样式 |
| `InputGesture` | 点击、按住、拖拽、释放、失焦取消的判定 | 直接选择 LLM 动作 |
| `WindowHitPolicy` | 可见模型/UI 命中与空白透明区点击穿透 | 以固定坐标猜测命中 |

接口名称是目标架构，不等同于现有 `DesktopPet`、`DragHandler` 或 `WindowOverlay` 已具备的类型。

## 3. 状态机与硬约束

```text
GroundIdle → AmbientWander → Walking → Brake → SettleStep → TurnTransition → Walking
     │              ▲              │
     └─ PostInteractionSettlement ← LocalResponse ← SoftLanding

Held → GentleRelease | Throw → Airborne → SoftLanding → PostInteractionSettlement
任意输入态 ──窗口失焦/取消──> GroundIdle | Airborne（按当前物理状态）
```

- **C-L2-01（物理唯一性）**：只有 `PhysicsRoot` 可写桌面位置/速度/落地状态。拖拽、自动散步、动作系统和 LLM 必须通过请求接口。
- **C-L2-02（边界）**：左右边界水平钳位、速度归零后自然下落；顶部取消上冲再下落；地面停住或自然转向。不得反弹穿出屏幕。
- **C-L2-03（拖拽抢占）**：拖拽时暂停空闲、LLM 和地面行为；失焦/取消不得制造抛掷速度。
- **C-L2-04（手势）**：短点击、按住、拖拽、轻放与抛掷使用距离/速度/时间阈值区分，且阈值可在隔离测试中注入。
- **C-L2-05（可见位移）**：自主持续水平移动仅在已认证、同步的步行技能可用时执行；否则仅允许微小局部调整或停留。
- **C-L2-06（转向）**：分离 `RequestedDirection` 与 `FacingDirection`；必须走减速、调整、可见转向/安全翻面、再起步。不得通过 `scale.x` 连续穿过零实现翻面。
- **C-L2-07（恢复）**：用户拖放/互动后先执行有限局部回应，再回到受控随机散步；不得无限贴边、重复折返或高频变向。
- **C-L2-08（输入可达）**：可见模型/UI 可命中；透明空白点击穿透。窗口不激活或不挡桌面是默认，直接交互时可靠性优先。
- **C-L2-09（主屏优先）**：当前活动区只位于主屏；发现多屏变化时保持安全钳位和正确坐标，不跨屏尝试完整行为。

## 4. 布局、缩放与持久化

- 默认模型高度按主屏可用高度的比例计算，保留用户缩放倍率及最小/最大安全范围。
- `DisplayLayout` 变化（DPI、分辨率、工作区、任务栏）后必须重算视觉大小、物理边界、命中区、地面线与活动区；不得只缩放渲染而不更新输入/物理。
- 正常退出保存最后稳定地面位置；非正常退出优先恢复最后一次明确拖放锚点。两者都要在新工作区钳位。
- 活动区以用户最后明确放置区域为初始锚点，逐步扩展；在小范围内优先选择看得出在走路的短步目标。

## 5. 失败与降级

| 情况 | 必须行为 | 禁止行为 |
|---|---|---|
| 未认证步行/动作冲突 | 停止长距离自主移动，降级为待机或小幅调整 | 视觉滑行或用不自然动作掩盖 |
| 布局无法确定 | 使用保守主屏安全区并记录原因 | 写出屏幕坐标、跨屏漂移 |
| 命中层/窗口重建失败 | 保证模型至少可见；本地恢复窗口样式 | 透明区整体吞鼠标或静默丢失输入 |
| 拖拽中断 | 清理拖拽占用，按当前物理状态安全收束 | 残留 `isDragging`、伪造投掷 |
| 动作/行走不可并行 | 通过动作协调器停止或排队 | 多方直接写同一姿态参数 |

## 6. 可观测性与验收

| 验收 ID | 场景 | 证据 | 通过标准 |
|---|---|---|---|
| AC-L2-01 | 左右/顶部/地面边界、自由落体 | 隔离 `@@sim` 状态日志与截图 | 无越界，边界规则符合 C-L2-02 |
| AC-L2-02 | 点击、按住、拖拽、轻放、抛掷、失焦 | 终端等价命令、状态序列、截图 | 手势正确分流，拖拽无残留占用 |
| AC-L2-03 | 左右移动、镜像后移动、转向 | 时序截图/视频帧、方向/朝向日志 | 无缩放穿零、倒走或肉眼可见滑行 |
| AC-L2-04 | 互动后局部回应与散步恢复 | 行为状态序列 | 有限回应后恢复，不贴边循环 |
| AC-L2-05 | DPI/分辨率/工作区变化 | 可重复布局测试和截图 | 模型比例、命中、物理与位置恢复一致 |
| AC-L2-06 | 透明空白与模型/UI 点击 | 真实窗口验证 + 终端状态链路 | 空白穿透；模型/UI 可交互；不抢焦点 |
| AC-L2-07 | 全部 L2 变更 | Quick、EditMode、隔离冒烟、生产数据保护断言 | 构建/适用测试通过且零生产数据污染 |

## 7. 待决项（已解决）

已由[首版默认运行阈值](../../decisions/default-operational-thresholds.md) L2 条款确认：默认模型高度为主屏可用高度 28%、用户倍率 70%–140%（D-L2-01）；拖拽阈值 12 px、轻放最大 180 px/s、超过即抛掷（D-L2-02）；活动区初始半径 3 倍模型宽度、每天最多扩展一倍、最大为工作区宽度 35%（D-L2-03）；普通用户只调缩放、活动范围和自动散步开关（D-L2-04）。

1. **D-L2-01**：默认模型高度占主屏可用高度的比例、最小/最大比例与用户倍率范围。
2. **D-L2-02**：点击/按住/拖拽/轻放/抛掷的默认时间、距离和速度阈值。
3. **D-L2-03**：活动区域初始半径、扩展速度和最大范围。
4. **D-L2-04**：普通用户可配置哪些布局/输入项，哪些仅开发者诊断可见。

## 8. 实施授权边界

- **未来允许范围**：`DesktopPet` 物理、拖拽输入、窗口命中、布局计算、隔离测试及直接说明文档。
- **禁止范围**：未经 L3 批准修改 Live2D 认证技能/参数语义；未经 L5 批准添加主动对话；未经 L1 批准改变退出/数据恢复策略。
- **阻断条件**：跨显示器自由移动、读取其他应用窗口、改变用户数据位置、引入新的可访问性/系统级输入权限，均必须 `BlockedByDecision`。
