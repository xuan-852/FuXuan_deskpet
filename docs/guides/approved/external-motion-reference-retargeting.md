# 外部动作参考导入与 3D→Live2D 受约束重定向

> **状态**：已批准；外部素材仍须逐项完成许可复核，才可进入受限任务包。
>
> **上位决策**：[产品方向基线 L3](../../decisions/2026-09-15-product-direction-baseline.md#4-l3具身动作与-live2d-能力认证)、[L3 具身技能认证指导](../approved/l3-embodied-skill-certification.md)、[具身智能指导](../../embodied-intelligence-guidance.md)。
>
> **代码真相**：[六项认证动作隔离运行时复验](../../truth/l3-six-certified-motion-isolated-runtime-verification.md)、[L3 LLM 接入具身控制](../../truth/l3-llm-embodied-integration.md)。

## 1. 目标与非目标

- **FR-RETARGET-01**：建立外部 2D/3D 动作仅作为离线参考的可追溯导入链，将合法来源转为版本化的语义特征包和候选曲线，而不是直接播放外部动作文件。
- **FR-RETARGET-02**：建立从 3D 骨架或视频姿势参考到当前 Live2D 已认证能力的受约束拟合；输出必须受模型能力、幅度、速度、平滑度、复位和资源约束限制。
- **FR-RETARGET-03**：以当前六项隔离运行时通过的认证动作为执行底座基线，逐步扩充头脸、躯干、单臂/双臂和收束过渡等可组合原语。
- **FR-RETARGET-04**：任何新技能仍须经过 L3 的机械、视觉、语义、自然度与真人签字门禁后才可部署或公开给 LLM。

非目标：不把 Live2D 描述为完整三维人体；不在运行时读取 3D 动作、视频或云端视觉；不直接导入 BVH/VMD/FBX/motion3.json 到符玄生产运行时；不把下肢、跳跃、旋转、镜头位移或不具备认证能力的舞蹈部分伪装成可表现动作；不因素材“开源”而忽略模型、动作、人物、音乐和再分发许可。

## 2. 范围、组件与公开接口

```text
许可清晰的动作参考
  → ReferenceManifest（来源与权利）
  → MotionFeaturePacket（语义与时序特征）
  → ConstrainedRetargetPlan（受约束候选曲线）
  → L3 候选证据/认证 → CertifiedMotionLibrary
```

| 组件/接口 | 输入 | 输出/副作用 | 所有者 |
|---|---|---|---|
| `ReferenceManifest` | 来源 URL、许可、作者、获取日、原始哈希、用途 | 只读来源账本；许可不清即拒绝 | 离线素材工具 |
| `MotionFeaturePacket` | 获准的 2D/3D 参考 | 时间归一化的头、躯干、手臂、手、节奏和停顿特征 | 离线重定向工具 |
| `ConstrainedRetargetPlan` | 特征包、能力目录、姿势约束 | 候选参数曲线、语义边界、降级说明和证据哈希 | 离线拟合器 |
| `RetargetAdmission` | 候选曲线与 L3 证据 | `Candidate` / `Rejected`；不得直接进运行时 | L3 认证流水线 |

`MotionFeaturePacket` 的首版规范化特征仅含：时间相位、头部 yaw/pitch/roll、躯干侧倾/前倾、左右上臂方向、前臂弯曲、手的屏幕空间轨迹、注视方向、停顿与节奏。所有左右字段必须额外标注 `screenSide` 或 `anatomicalSide`，禁止无标记混用。

## 3. 数据、状态与资源

```text
Discovered → LicenseReviewed → FeatureExtracted → Fitted → Candidate
                                  │                    │
                                  └──── Rejected ──────┘
Candidate → LocalVerified → VisualReviewed → HumanSigned → Certified
                                         │
                                         └── Rejected / NeedsEvidence
```

- 原始素材、视频、BVH/VMD/FBX、音乐和派生曲线默认不入版本库；仅在本地许可目录或隔离数据根保存，保留来源和内容哈希。
- 仓库可保存不含受限素材的 `ReferenceManifest`、特征摘要、候选证据哈希、许可证结论和认证结论。
- `ConstrainedRetargetPlan` 是离线候选，不拥有 `ActionRequest`、Live2D 参数写入或 LLM 暴露权；只有 `CertifiedMotionLibrary` 的认证条目才可由运行时读取。
- 候选曲线与模型版本、映射版本、能力目录版本和参考包哈希绑定；任一项变化使认证至少降为 `NeedsEvidence`。

## 4. 重定向模型与硬约束

### 4.1 受约束拟合

3D 参考只提供相对方向、时序与节奏；Live2D 以已认证的语义能力近似表达。首版拟合目标为：

```text
J = wp × 姿态特征误差
  + wv × 速度误差
  + ws × 平滑度（速度/加速度/jerk）
  + wr × 复位误差
  + wc × 组合冲突惩罚
```

优化变量只能是能力目录已允许的语义通道；每项幅度、速度、加速度、jerk、总时长、资源占用和收束误差都有硬上限。无法由已认证能力表达的特征必须从计划中删除并给出 `Unsupported` 或近似技能降级，绝不能用未经认证参数补齐。

### 4.2 硬约束

- **C-RETARGET-01**：来源须逐项记录确定 URL、许可文本/版本、访问日期、原始主张和使用方式；任何一个缺失即 `BlockedByEvidence`。
- **C-RETARGET-02**：外部素材许可与 SDK/模型许可分开审核。允许离线研究不代表允许生产部署、再分发或派生曲线分发。
- **C-RETARGET-03**：原始 3D 骨架坐标不得直接映射到 `Param*`；重定向只能经过语义特征、能力目录和离线候选计划。
- **C-RETARGET-04**：运行时不加载原始参考素材、不联网、不调用云端视觉；外部素材不会获得工具、文件或桌面读取权限。
- **C-RETARGET-05**：动作库少于 30 项时，防夸张只采用技能级可解释阈值、金样本回归和人工审计；不以不稳定的全库协方差/MMD 自动裁决。
- **C-RETARGET-06**：任何人形左右归属、自然度、安全或许可分歧不得由单一模型裁决；按 L3 指导升级人工决定。
- **C-RETARGET-07**：生产曲线必须实施内容哈希与认证包/技能版本绑定；加载不匹配、缺失或未知曲线时拒绝播放且不降级为原始参数控制。

## 5. 失败、降级与恢复

- **FR-RETARGET-05**：许可不清、哈希不一致、能力缺失、约束无解或本地复位失败时，候选终态为 `Rejected` 或 `NeedsEvidence`，不调用 LLM 或云端进行补救。
- **FR-RETARGET-06**：下肢、跳跃、全身旋转和大范围 Root 位移等不可表达部分，优先保留可认证的上半身节奏、视线或轻微躯干表达；无安全近似时向普通用户退化为文字/不执行，技术细节仅入调试记录。
- **FR-RETARGET-07**：候选在隔离运行时发生抢占、超时、渲染器失效或异常时，必须沿现有 `SafeRecovery` 路径恢复姿势并释放租约；该失败不能污染生产记忆或认证库。

## 6. 可观测性与验收

| 验收 ID | 条件 | 自动化/证据 | 通过标准 |
|---|---|---|---|
| AC-RETARGET-01 | 参考素材入库 | `ReferenceManifest` 及人工许可复核 | URL、许可、哈希、获取日和用途完整；无权利结论不得进入下一状态 |
| AC-RETARGET-02 | 特征提取 | 隔离 `MotionFeaturePacket` | 含时间相位、部位/屏幕侧标记、置信度、源哈希；不含原始素材嵌入 |
| AC-RETARGET-03 | 候选拟合 | 局部约束报告和曲线证据 | 全部通道均在能力目录与技能级幅度/速度/jerk 限制内；不可表达特征有降级说明 |
| AC-RETARGET-04 | 离线运行时 | 隔离 Player、日志和截图 | 准入、播放、姿势还原、资源释放均完成；无超时、无原始参数入口、零云端调用 |
| AC-RETARGET-05 | 语义/自然度 | L3 本地证据、控制样本、独立复核和真人签字 | 达到 L3 认证门槛；未签字条目保持候选 |
| AC-RETARGET-06 | 生产部署 | 曲线哈希、认证包哈希、真实聊天路径和人工观察 | 只加载匹配曲线；缺失/篡改被拒绝；完整播放与自然收束可复核 |

## 7. 首轮实施建议

首轮只选择一个已明确可表达的非舞蹈上半身参考（例如“抬头后轻点头”或“单臂克制招呼”），先验证素材账本、特征包、受约束拟合与认证链的端到端闭环。舞蹈只能在该闭环通过后另立任务：先抽取上半身节奏和停顿，排除腿部、跳跃、旋转与大位移。

可作为“参考来源许可待复核”的起点：CMU Motion Capture Database 的官方说明允许研究及商业产品使用、禁止直接转售数据；Live2D 官方 SDK 与示例模型/素材适用不同许可，必须分别核查。访问与核对日期：2026-09-18。<https://mocap.cs.cmu.edu/> <https://github.com/Live2D/CubismUnityMotionSyncComponents/blob/develop/LICENSE.md>

## 8. 实施授权边界

- **未来允许范围**：离线来源账本、特征提取、受约束候选拟合、隔离测试、认证证据、曲线完整性校验、直接文档和任务包。
- **禁止范围**：下载或提交许可未核实素材、分发原始素材或未确认派生曲线、运行时 3D/视频/云端控制、原始参数 LLM 接口、修改正式映射/模型资源、把候选放入主动行为。
- **依赖/冲突门槛**：如许可含义、模型/映射版本、认证门槛、预算或隐私边界变化，须 `BlockedByDecision`。涉及外部素材的每批次在执行前还须满足 DG-31 的确定来源复核。
