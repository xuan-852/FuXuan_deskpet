# UI 验收清单（考评师版）— 含多模态验证项

> **文档作用**: 对桌宠 UI（内嵌面板 + 外置独立窗口）做**严格验收**的完整清单。每项标注**验收方式**：👁️=多模态视觉模型（GLM-4V 截图评估）、⌨️=终端链路（inbox 命令，铁律 §6.6）、🪟=Win32 枚举、🖐️=人工。改动 UI 后按此清单回归；交付前按此清单签发。
> **基本架构**: 面板 = Unity IMGUI 渲染（内嵌屏幕窗口 / 外置 RT 像素桥），尺寸三档（486×1269 会话列表 / 1290×1269 聊天 / 860×900 子面板），外置窗口 = Win32 原生普通窗口（44px 自绘星空标题栏 + 命中表交互 + 原生 EDIT 输入）。
> **开发历史迭代**: 2026-08-16 外置窗口 A1-A6/B1-B3 阶段踩坑 10+（黑屏/倒图/偏色/拖不动/输入失效/白框），已修并纳入本清单防回归（详见 `project-bugs-and-acceptance.md` 第二节）。
> **编写注意事项**: ① 清单中的坐标/尺寸以代码常量为准（`RightPanel.cs` L183-225、命中区 Rect 字面量），改代码后同步更新；② 多模态验证 = 截图喂 GLM-4V 描述/评分，**不替代**终端链路功能断言；③ 外置窗口测试一律用 `@@view:extclick` 或 Win32 枚举，**禁止移动真实鼠标**（铁律）。

## 〇、验收总则（考评师立场）

| 原则 | 说明 |
|------|------|
| 分层验收 | 视觉层（排版/颜色/动效，多模态）→ 功能层（状态机/命中区，终端链路）→ 窗口层（Win32 行为）→ 体验层（人工手感） |
| 多模态定位 | 视觉模型是**排版与视觉缺陷的哨兵**：黑屏/倒图/偏色/重叠/溢出/对比度——它一眼就能抓到，且免移动鼠标 |
| 功能断言定位 | 交互正确性（点了能不能切过去、命中区对不对）**必须**走终端链路，视觉模型只看"长什么样"不猜"能不能点" |
| 失败分级 | 🔴 P0 阻塞（黑屏/白屏/崩溃/无法交互）→ 🟠 P1 严重（布局错乱/文字不可读/按钮失效）→ 🟡 P2 一般（间距/颜色/动效细节） |
| 截图规范 | 每视图至少 3 张：静止态 / 交互态（hover 或注入后）/ 深色背景桌面（验证透明与星空） |

## 二、基本功能（交互正确性）— 终端链路主战场

> 验收方式以 ⌨️ 为主（inbox 命令，免真实点击），关键状态机由 Player.log 留痕断言。

| # | 验收项 | 方式 | 命令/断言 |
|---|--------|------|----------|
| F1 | 面板开合 | ⌨️ | `@@view:open`/`@@view:close` → `[TestInbox] @@view 命令: open/close`；关闭走淡出（`_animAlpha` 到 0.001 才隐藏） |
| F2 | 视图切换 | ⌨️ | `@@view:chat`（无会话建默认）、`@@view:list`、`@@view:back`；窗口尺寸随之切换（486⇄1290⇄860）且左上角保持 |
| F3 | 子面板进出 | ⌨️ | `@@view:settings/reminders/report/usage` 打开 → `@@view:back` 返回来源视图；`DrawPanelContent` 子面板分支含 `PanelView.Usage`（防误渲染回归） |
| F4 | 外置模式进出 | ⌨️ | `@@view:external` → 外置窗口创建（`[ExternalChat] 独立窗口已创建`）；`@@view:embed`/✕ → 退出内嵌 |
| F5 | 外置点击命中表 | ⌨️ | `@@view:extclick:100,200,true` 双击会话进聊天；`@@view:extclick:753,87` 工具行进设置；`@@view:extclick:15,15` 子面板返回 |
| F6 | 表情注入 | ⌨️ | `@@emote:happy` → 左侧气泡 + 右上徽章 + 形象跳跃（`已注入表情: happy`） |
| F7 | 审批弹窗 | ⌨️ | `@@approval:xxx` → 模态弹窗出现（下层命中区清空，只留三按钮），确认/取消后 `已注入测试审批` |
| F8 | 中文发送不乱码 | ⌨️🪟 | 发送中文消息 → 历史记录与回复均正确显示（CharSet.Unicode 封送） |
| F9 | 输入框聚焦 | ⌨️🪟 | 点输入区 → 原生 EDIT 获得焦点可键入（`WM_APP_FOCUS_INPUT` 链路） |
| F10 | 工具提示 | 👁️🖐️ | hover 工具行「设/签/告/耗」右侧浮出说明文字（tooltip y≈1276-1326） |
| F11 | 滚动列表 | ⌨️ | 会话列表/便签长列表滚动偏移补偿正确（命中矩形 +viewRect - scrollPos） |

## 三、进阶前端（窗口行为 / 渲染质量）— 多模态 + Win32 混合

> 用户核心诉求 = "标准窗口行为"（QQ 式）。窗口层用 🪟 断言，渲染质量用 👁️。

| # | 验收项 | 方式 | 通过标准 |
|---|--------|------|---------|
| A1 | **可被其他窗口遮挡（非置顶）** | 🪟 | 外置窗口 `exStyle` 无 `WS_EX_TOPMOST(0x8)`；桌宠主窗仍带 `WS_EX_TOPMOST`（本体置顶不变）——用户最核心诉求 |
| A2 | 拖动 | 🪟🖐️ | 标题栏 44px 区 HTCAPTION 拖动，跟手无漂移、无"固定在离鼠标 420px"类偏移（第二级必须用窗口原点算 offset） |
| A3 | 右下角缩放 | 🪟🖐️ | 20px 角区 HTBOTTOMRIGHT 拖拽缩放，松手不吸鼠标（MouseUp 复位 `_isDragging/_isResizing`） |
| A4 | 最小化/关闭 | 🪟⌨️ | 最小化到任务栏可恢复；✕（WM_CLOSE）= 隐藏并退回内嵌，不杀进程 |
| A5 | 标题栏按钮防吞 | 🪟⌨️ | 右上 68px 按钮区必须 HTCLIENT（点击优先于拖动）；◀/字体/⧉/✕ 均响应（防 `23bbb92` 回归） |
| A6 | 渲染质量 | 👁️ | 无黑屏（Repaint 门控）、无倒图（biHeight 正）、无偏色（BGRA32）、无闪烁（15fps 节流 + ValidateRect 防风暴） |
| A7 | 星空动效 | 👁️ | 星点分层 + 流星拖尾（采样 0.033s/点 ≡ 2·vx 间距）运动流畅，无跳变/断裂（与 60fps 内嵌一致） |
| A8 | 淡入淡出 | 👁️ | 开合透明度过渡平滑（FADE_SPEED=5f）；星星/拖尾自设颜色正确乘 `_animAlpha`（防淡出失效回归） |
| A9 | DPI 缩放 | 🪟⌨️ | 144 DPI 下 `@@view:extclick` 坐标 ×(逻辑/物理) 比例换算正确，点击不错位 |
| A10 | 位置记忆 | 🪟 | 移动/关闭后重开，PlayerPrefs 恢复上次位置；屏幕外位置自动校正回屏内 |
| A11 | 审批模态 | 👁️⌨️ | 弹窗打开时下层按钮不可点（`_extHitZones.Clear()`），模态视觉覆盖正确 |
| A12 | 性能 | 🪟 | 外置渲染 15fps 节流不失控；窗口线程不阻塞 Unity 主线程（消息循环 GetMessageW） |

## 五、回归红线（改 UI 代码后必查）

1. **外置窗口渲染四连**：黑屏（Repaint 门控）→ 倒图（biHeight 正）→ 偏色（BGRA32）→ 闪烁（节流+ValidateRect）
2. **命中表三兄弟**：标题栏拖动（HTCAPTION+DefWindowProc）↔ 按钮点击（68px HTCLIENT）↔ 缩放角（HTBOTTOMRIGHT）——互不吞
3. **P/Invoke DLL 归属**：`SetTextColor/SetBkMode`=gdi32、`GetModuleHandleW`=kernel32、窗口 API=user32——错一个杀窗口线程
4. **子面板分支**：新增视图必须进 `DrawPanelContent` 分支 + inbox 命令表补等价命令（`HandleTestViewCommand`）
5. **GUI.color 复位**：任何自设颜色后必须恢复 `Color.white`，否则全局淡入淡出失效
6. **滚动偏移补偿**：列表命中矩形必须加滚动偏移，否则滚动后点击错位

## 六、验收执行脚本（自动化骨架）

```powershell
# 1) 构建 + 冒烟（含 UI 功能断言）
.\build.ps1 -Quick
node scripts/test/runtime_smoke.cjs   # 命令留痕/尺寸/零NRE/记忆零污染

# 2) 多模态视觉采样（需测试模式 + 外置窗口打开）
#    截图源：外置窗口客户区（Win32 BitBlt）或隔离目录渲染缓存
#    喂 GLM-4V：五维评分（元素齐全/对齐/重叠溢出/颜色/可读性）

# 3) Win32 断言
#    EnumWindows 找 FuXuanChatWindowClass → GetWindowLong exStyle 无 0x8
#    GetClientRect 对比三档尺寸；SendMessageW 驱动最小化/关闭
```

> 多模态采样建议：每次回归至少抓「会话列表 / 聊天 / 设置 / 便签 / 报告 / 消耗 / 审批弹窗 / 外置标题栏」8 张，对照 L1-L10 逐项打分，P0/P1 项一票否决。
