# Live2D 平台与符玄私有 Fixture 范围决策

> **状态**：已确认的项目方向决策（2026-09-18）。
> **替代关系**：本决策替代“符玄二创 Live2D 模型生产计划”作为当前的实施方向；原文保留在 [`docs/archive/fuxuan-private-fixture-case-study.md`](../archive/fuxuan-private-fixture-case-study.md) 供历史追溯。
> **关联指导**：[`Live2D 运行时平台与模型适配器`](../guides/approved/live2d-runtime-platform-and-model-adapter.md)。

## 1. 决策

项目当前优先建设可复用的桌宠运行时平台、模型适配边界、能力探测和安全状态闭环，而不是继续把某个角色模型的生产交付作为平台主线。

现有符玄资源和 `model-workspaces/fuxuan-derivative-v1/` 只作为本地私有运行时宿主、适配案例和失败证据。它们不构成平台代码的再分发许可，也不自动获得角色 IP、模型作者或外部素材的改作、商业或发布授权。

## 2. 固定状态

- 符玄工作区：`FixtureOnly / CaseStudy`。
- 当前分层绘稿验收：`ReviewFailed`；视觉失败优先于结构检查通过。
- 官方视觉和角色衍生权利：许可证据不足时为 `BlockedByEvidence`。
- 不创建或验收 Cubism `.cmo3`、新导出物、Unity 生产候选、正式参数映射、生产动作、LLM 技能或安装包资产。
- 不将当前固定 Fuxuan 加载路径描述为通用换模或热插拔能力。

## 3. 公开边界

可以公开平台代码、通用接口、探测协议、测试工具、运行时状态机和不含受限角色资产的文档。不得在没有单独权利复核的情况下公开、商业化、再分发或随安装包交付第三方模型、纹理、动作、参数专属配置、Cubism 工程、导出物、角色截图或组合包。

用户自备模型必须由用户自行确认具有合法使用权；平台代码许可不延伸到角色 IP、第三方模型或用户导入资产。

## 4. Fixture 变更门禁

任何将 fixture 恢复为生产候选的请求，都必须重新建立：

1. 新的方向决策和批准指导文档；
2. 独立任务包、允许/禁止路径和回滚方案；
3. 权利与来源复核；
4. 可复核的人工视觉验收；
5. 隔离导入、Probe 证据和能力认证；
6. 明确的发布、安装包和再分发审查。

不得通过修改旧批准文档、旧任务包或 `docs/truth/` 状态记录绕过上述门禁。
