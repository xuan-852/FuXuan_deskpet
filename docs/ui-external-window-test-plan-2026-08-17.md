# 外置独立面板专项测评方案（codex 第三轮）

> 测评对象：**外置独立 PC 窗口（`FuXuanChatWindowClass`）**，即点击面板标题栏 ⧉ 按钮后出现的可被遮挡的 Win32 普通窗口。
> ⚠️ **不是** Unity 内嵌面板（屏幕上的 `~` 呼出面板）——内嵌面板已稳定，本轮只测外置窗口的交互链路。
> 背景（2026-08-17 用户实测反馈）：外置面板**多个点击有 bug、拖动时灵时不灵**。前两轮 codex 复验以程序化注入为主（PostMessage/SendMessage），可能未覆盖真实鼠标时序。本轮要求**真实鼠标/键盘优先**，程序化注入仅作对照。

---

## 一、前置条件

1. 使用最新构建（`9bdf4f7` 之后若有修改则用最新 `Build/DesktopPet.exe`）。
2. 启动方式：隔离目录 + 测试模式（避免污染生产记忆）：
   ```powershell
   $env:FU_XUAN_DATA = "$env:TEMP\fuxuan_ext3_test"; New-Item -ItemType Directory -Force $env:FU_XUAN_DATA | Out-Null
   New-Item -ItemType File "$env:TEMP\fuxuan_ext3_test\.test_mode" | Out-Null
   Start-Process .\Build\DesktopPet.exe
   ```
3. 进入外置面板（终端链路）：
   ```
   @@view:open → @@view:chat → @@view:external
   ```
4. 记录环境：DPI（`GetDpiForWindow` 或注册表）、显示器分辨率、缩放比例。
5. 复验脚本建议：真实鼠标用 `SendInput`（绝对屏幕坐标，模拟真实用户移动+按下+释放+移动）；真实键盘用 `SendInput` 键盘事件。**仅 PostMessage 注入不能触发系统 MoveLoop（拖动），会漏测拖动时序。**

## 三、重点怀疑项（codex 排查线索，基于代码审查）

1. **命中表时序**：`_extHitZones` 在 `DrawExternalPanelToTexture` 每渲染帧重建（`EventType.Repaint` 才走）；`DrawPanelContent` 审批时 `_extHitZones.Clear()`（L991）会清空但**不重建**——若审批弹窗关闭后恰在非 Repaint 帧点击，命中表可能为空 → 「点击没反应」。
2. **拖动边界判定**：`WM_NCHITTEST` 中 `ly <= TITLE_BAR_H`（44 逻辑）在 144 DPI 下 = 物理 66px，`WM_NCLBUTTONDOWN` 的 lParam 是屏幕坐标（物理），`WM_NCHITTEST` 的 lParam 也是屏幕坐标——两者应一致，但需实测边缘 2px 内是否抖动（时灵时不灵可能源于此）。
3. **双击时序**：`WM_LBUTTONDOWN` 每次触发 `OnPanelClick`，双击 = 两次单击 + 一次 `WM_LBUTTONDBLCLK`；会话项双击进聊天若单击有副作用（如高亮/选中态），快速连点可能状态错乱。
4. **拖动时命中表残留**：拖动（HTCAPTION）不经过 `OnPanelClick`，但若 `WM_NCLBUTTONDOWN` 未正确转发（DPI 边界判定漂移成 HTCLIENT），按下会走 `WM_LBUTTONDOWN` → 点击而非拖动 → 「拖动时灵时不灵」。

## 四、证据要求（每项必录）

1. Player.log 关键留痕：`外部点击命中/未命中`、`input hit/focused/send`、`外部标题栏`、`视图切换`、异常堆栈。

3. DPI 探针输出：`GetClientRect` 客户区尺寸（DPI-aware 视角）——确认与 `_width/_height` 逻辑一致。
4. 失败复现的最小步骤（精确到坐标、速度、次数）。
5. `IsIconic` / `IsWindowVisible` 状态快照。

## 五、验收门槛

外置独立面板可签收需同时满足：

- 标题栏拖动：10/10 成功，无中途丢失/跳变，边界 2px 内行为稳定。
- 内容区点击：会话双击/返回/字体/工具行/输入框全部 10/10 命中，无"点了没反应"。
- 标题栏按钮：最小化/关闭 10/10，按钮边缘不误触拖动。
- 输入：中文键入 + 回车发送完整链路（`外部窗口发送:` 日志 + 历史记录）。
- 缩放/位置记忆/可遮挡/DPI 命中：全部通过。
- Player.log 零 NRE / Fatal / Unhandled。
- 测试模式隔离：生产记忆零污染。
