# 第三方与模型许可边界

本文件只说明责任边界，不授予任何角色、模型或服务的额外许可。

## 平台代码

桌宠运行时、工具系统、桥接、测试脚本和不含受限素材的文档，按仓库各文件的许可证和贡献规则处理。代码许可不包含角色 IP、第三方模型、纹理、动作、参数专属配置或组合安装包。

## Live2D/Cubism SDK

Cubism Editor、SDK、运行时和导出工具按其各自许可使用。使用 SDK 编译平台不等于取得任何角色模型或第三方素材的再分发权。

## 角色与第三方模型

符玄等角色及其视觉识别元素属于相应权利人。现有 `Fuxuan` 模型包、纹理、动作、物理、网格、导出物和专属参数配置按来源登记处理；许可不明确时状态为 `BlockedByEvidence`。不得仅因“免费”“开源”“可下载”或“私用”描述推断可以改作、发布、商业化或随安装包交付。

仓库中的既有跟踪资源不会因 `.gitignore` 更新而自动从 Git 索引或历史删除。本轮没有执行 `git rm --cached` 或历史重写；公开仓库脱敏需要单独的权利复核、迁移方案和人工批准。

## 用户自有模型

用户可以在本地提供具有合法使用权的模型资源，并在隔离目录记录来源、许可、版本和哈希。用户负责确认角色 IP、纹理、动作、字体、外部参考和组合分发的权利；平台不替用户作法律判断。

## 外部动作与参考素材

官方示例、外部动作包和参考图像必须单独登记来源、访问日期、原始许可和实际使用范围。探测或适配不得复制像素、纹理、网格、曲线、物理、动作、工程或导出物。公开视觉最多作为人工观察参考，不能自动成为可处理素材。

## Ollama 与云端服务

Ollama 本地模型 tag、DeepSeek/GLM 等云端服务和 OpenClaw 是独立服务依赖，按各自服务条款和密钥责任处理。LLM 模型 tag 不是 Live2D 角色模型；代码支持的模型名覆盖不表示支持任意权重文件导入或通用 provider 分发。

## 公开发布与安装包

平台发布前必须从发布物中排除未经权利复核的模型、纹理、动作、Cubism 工程、参数映射、角色截图和组合资源。任何展示、商业化、再分发、源工程提供或安装包交付，都需要重新复核平台、模型资源和角色 IP 三方边界，并以最严格的许可为准。
