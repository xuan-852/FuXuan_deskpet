# L3 招手组合能力普查（2026-09-18）

## 结论

当前符玄模型已经证明具备制作“完整招手候选”的最低底层通道：可见的抬臂、手腕候选、手型切换，以及可复位的面部候选通道。它**不等于招手动作已完成或已认证**；目前没有任何招手曲线、正式映射、生产数据或 LLM 可调用技能。

最重要的限制是：单独扫动手腕或普通手指时，正面可见差异很弱。真正可读的招手必须在抬臂姿态中，利用手型切换形成面向观者的手掌，并对手腕作有限、节律化的往返；脸部还须在组合动作内再次人工验收。

## 风险与下一步

`Param102` 在静态映射文件中标为 `0..1`，但组合探针从运行时模型范围取得的目标为 `15`（以 0.5 比例缩放）。这说明静态名称和范围只能是候选资料，后续制作前必须以运行时原生范围为准，并在更保守范围内重新取样。

下一任务应先产出一个**不暴露给 LLM**的招手候选：准备 → 抬臂 → 手型定向 → 至少两次小幅腕部往返 → 表情配合 → 回落。候选必须在真实可见桌宠窗口中由人工完整观看；只有确认“手在挥、看起来友好、结束自然”后，才可讨论认证与受控暴露。
