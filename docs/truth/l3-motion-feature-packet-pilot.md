# L3 外部动作特征包试点验证

> **验证日期**：2026-09-18  
> **输入**：本地 Cubism Web Samples 的 `Hiyori_m02.motion3.json`；测试输出位于带 `.test_mode` 的临时目录。

## 结果

`scripts/live2d-probe/extract_motion_features.cjs` 已将一份外部 `.motion3.json` 解析为只读的 `l3-motion-feature-packet/v1`：

| 项目 | 结果 |
|---|---:|
| 识别特征通道 | 14 |
| 源文件 SHA-256 | `858c582874a0c4badfec38d4caf19e232fea5ba714f5a2ac6a282c617910c154` |
| 声明时长 | 5.930 s |
| 曲线观测时长 | 5.933 s |
| 归一化相位 | 全部单调且位于 `[0, 1]` |
| 候选曲线 / 符玄参数映射 / 运行时数据写入 | 0 |
| 云端调用 | 0 |

Cubism 的 `Meta.Duration` 可能因精度截断而略小于曲线终点；提取器以声明时长和观测终点的较大值归一化，避免末帧相位越过 1。

## 边界与结论

该产物只保留头、躯干、视线、眼睛、手臂和手部的源动作证据；源参数语义仍标为未验证。它不能生成可播放曲线、不能建立符玄参数映射，也不能绕过 L3 的候选重建、认证和人工验收。

这证明了“外部动作 → 可审查特征参考”的离线路径可行；不证明外部动作可直接移植到符玄，更不构成新增认证动作。
