# L3 动作评审条带试点：GLM-4.6V / Qwen3-VL 判别力实测

> **证据日期**：2026-09-18  
> **背景**：认证评审此前用 2×2 静态拼图，无法表达 5 秒连续动作的时序；本试点验证"运动条带 + 差异热图 + 结构化提问 + 盲比对"的证据形式下各视觉模型的判别力。  
> **素材**：躯干 Z 隔离根 25 张裁剪帧（`%TEMP%\fuxuan_torso_dynamic_z_20260917`），正样本（顺序条带）、负样本（乱序条带）、静止对照（首帧重复）。外发仅发给智谱 GLM（`glm-4.6v`，三轮 9 次）与阿里云百炼（`qwen3-vl-plus`，两轮 6 次），合计约 10 万 tokens（远低于预算线）。

## 三轮结果

| 轮次 | 证据形式 | 正样本 | 乱序负样本 | 静止对照 |
|---|---|---|---|---|
| 1 | 16 帧×240px 拼图，整体打分 | 连贯 ✓ | 连贯 ✗ | 连贯 ✗（对 16 张相同帧编造"褶皱逐渐展开收拢"） |
| 2 | 8 帧×420px + 差异热图，强反脑补提示 | static ✗ | static ✗ | static ✓ |
| 3 | +逐张分级 + 盲描述 + 纯文本边界比对 | rise-fall + "向右侧摆动后回正" + supported ✓ | 边界比对 **unsupported** ✓（部位不吻合） | **✗**：对全黑热图编造 `d04=3` 的假轨迹并通过比对 |

## Qwen3-VL-plus 对照（2026-09-18 补测）

| 项目 | 结果 |
|---|---|
| 静止对照逐张分级 | **全 0（真接地）**——GLM-4.6V 在同一对照上编造了 rise-fall |
| 正样本逐张分级 | `0,1,2,3,2,1,1,0`，与本地像素差轨迹吻合 |
| 轨迹判断 | 正样本 rise-fall ✓；乱序样本仍误判 rise-fall ✗ |
| 语义盲描述 | 偏向衣摆/飘动的物理后果（身体侧倾的可见表现），合理但需比对规则配合 |
| 边界比对 | 严格部位规则 → 正样本误拒；放宽"衣物为身体动作可见后果"规则 → 乱序负样本误放行 |
| 稳定性 | 约 1/6 调用返回空 content（`completion_tokens=1`，finish=stop），生产使用需重试 |

## 最终结论（实测后修订）

1. **GLM-4.6V**：感知层不可靠（编造分级），文本推理与比对可用；适合作为文本比对/复核角色，不适合做视觉主判。
2. **Qwen3-VL-plus**：视觉接地能力真实存在（诚实分级、静止判对），是当前推荐的语义评审主判；但轨迹推断与比对规则仍会摇摆，且偶发空响应需要重试兜底。
3. **架构定论**（不变并强化）：
   - 存在性、轨迹（rise-fall/erratic/none）、幅度、复位 → **本地像素指标硬判定**，这是唯一可信的"是不是乱动"裁决者；
   - 本地判定为连贯动作时，才送模型做盲语义描述 + 边界比对，**本地轨迹作为事实输入比对步骤**（不给模型自由推断轨迹的空间）；
   - 该架构下三样本全部判对：static 被本地短路、shuffled 被本地 erratic 短路、ordered 由 Qwen3-VL 语义比对通过。

## 工具与证据

- `scripts/live2d-probe/make_motion_strip.py`：条带生成（--diff 差异热图 / --shuffle 负样本 / --static 对照）。
- `scripts/live2d-probe/review_motion_strip.cjs`：GLM 结构化评审（逐张分级 → 盲描述 → 纯文本边界比对，两段调用）。
- 评审 JSON 与条带图保留在隔离根 `strips/`（含 `.test_mode`），不入版本库。
