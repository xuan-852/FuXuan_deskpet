# L3 动作评审条带试点：GLM-4.6V / Qwen3-VL 判别力实测

> **证据日期**：2026-09-18  
> **背景**：认证评审此前用 2×2 静态拼图，无法表达 5 秒连续动作的时序；本试点验证"运动条带 + 差异热图 + 结构化提问 + 盲比对"的证据形式下各视觉模型的判别力。  
> **素材**：躯干 Z 隔离根 25 张裁剪帧（`%TEMP%\fuxuan_torso_dynamic_z_20260917`），正样本（顺序条带）、负样本（乱序条带）、静止对照（首帧重复）。外发仅发给智谱 GLM（`glm-4.6v`，三轮 9 次）与阿里云百炼（`qwen3-vl-plus`，两轮 6 次），合计约 10 万 tokens（远低于预算线）。

## 三轮结果

| 轮次 | 证据形式 | 正样本 | 乱序负样本 | 静止对照 |
|---|---|---|---|---|
| 1 | 16 帧×240px 拼图，整体打分 | 连贯 ✓ | 连贯 ✗ | 连贯 ✗（对 16 张相同帧编造"褶皱逐渐展开收拢"） |

## Qwen3-VL-plus 对照（2026-09-18 补测）

| 项目 | 结果 |
|---|---|
| 静止对照逐张分级 | **全 0（真接地）**——GLM-4.6V 在同一对照上编造了 rise-fall |
| 正样本逐张分级 | `0,1,2,3,2,1,1,0`，与本地像素差轨迹吻合 |
| 轨迹判断 | 正样本 rise-fall ✓；乱序样本仍误判 rise-fall ✗ |
| 语义盲描述 | 偏向衣摆/飘动的物理后果（身体侧倾的可见表现），合理但需比对规则配合 |
| 边界比对 | 严格部位规则 → 正样本误拒；放宽"衣物为身体动作可见后果"规则 → 乱序负样本误放行 |
| 稳定性 | 约 1/6 调用返回空 content（`completion_tokens=1`，finish=stop），生产使用需重试 |

## 描述变体实验（2026-09-18 补充：语义边界的质量被证实是瓶颈之一）

固定盲观察记录（qwen3-vl-plus 与 gemini-3.7-flash 两份），仅替换边界描述文本、由 gemini-3.7-flash 做文本比对：

| 边界描述版本 | 正样本判定 | 乱动负样本判定 |
|---|---|---|
| V1 原版："保守幅度的全身躯干侧倾并回到基线" | supported ×2 | **qwen 放行 ✗**（vague 到能解释乱动） |
| V2 可观察版："身体缓慢向画面右侧倾斜，衣物裙摆披风随之同侧摆动后回直" | supported ×2 | **unsupported ×2** |
| V3 认证风格（V2 + 排除项"非挥手/跳跃/位移，方向不往返"） | supported ×2 | **unsupported ×2** |

**结论**：语义边界必须用可观察语言书写——① 方向明确；② 描述视觉后果（衣物摆动）而非仅参数意图（躯干倾斜）；③ 带排除项。这与外部动作导入时的教训一致（`l3-external-motion-import.md`：语义边界由帧审查拟定并作为候选包必备字段）。"保守幅度"这类不可校准的措辞会直接把负样本放进 supported。后续所有新边界声明按 V3 风格书写并纳入认证检查项。

## 最终结论（实测后修订）

1. **视觉接地（静止判静）**：Qwen3-VL 与两代 Gemini 都诚实；GLM-4.6V 是五模型中唯一编造者——不是越贵越稳，GLM 不适合做视觉主判。
2. **语义精度是全模型共同短板**：保守幅度的躯干侧倾被所有模型弱化描述为"待机晃动/呼吸起伏/裙摆摆动"。根因是证据物理对比度低（峰值平均像素差仅 ~20）且方向信息在条带图上难辨——这靠换模型解决不了，靠提高证据对比度（幅度归一化增强、前后帧叠化图、或直接把本地参数轨迹图作为证据之一）解决。
3. **没有任何模型能在"模型单独裁决"模式下三样本全对**，五模型数据一致支持分层架构：
   - 本地像素指标硬判存在性/轨迹/复位（乱动在此短路）；
   - 本地判定连贯后，才送视觉模型做盲语义描述，本地轨迹作为事实输入比对；
   - GLM-4.6V 用于文本比对复核；Qwen3-VL-plus 为语义主判（接地诚实 + 现有 Key 零新增账号）。
   - 该架构下三样本全部判对，且结论对模型选择不敏感。
