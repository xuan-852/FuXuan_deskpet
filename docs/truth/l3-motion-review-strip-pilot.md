# L3 动作评审条带试点：GLM-4.6V 判别力实测

> **证据日期**：2026-09-18  
> **背景**：认证评审此前用 2×2 静态拼图，无法表达 5 秒连续动作的时序；本试点验证"运动条带 + 差异热图 + 结构化提问 + 盲比对"的证据形式下 GLM-4.6V 的判别力。  
> **素材**：躯干 Z 隔离根 25 张裁剪帧（`%TEMP%\fuxuan_torso_dynamic_z_20260917`），正样本（顺序条带）、负样本（乱序条带）、静止对照（首帧重复）。全部外发仅发给智谱 GLM，模型 `glm-4.6v`，三轮共 9 次调用合计约 6 万 tokens（远低于预算线）。

## 三轮结果

| 轮次 | 证据形式 | 正样本 | 乱序负样本 | 静止对照 |
|---|---|---|---|---|
| 1 | 16 帧×240px 拼图，整体打分 | 连贯 ✓ | 连贯 ✗ | 连贯 ✗（对 16 张相同帧编造"褶皱逐渐展开收拢"） |
| 2 | 8 帧×420px + 差异热图，强反脑补提示 | static ✗ | static ✗ | static ✓ |
| 3 | +逐张分级 + 盲描述 + 纯文本边界比对 | rise-fall + "向右侧摆动后回正" + supported ✓ | 边界比对 **unsupported** ✓（部位不吻合） | **✗**：对全黑热图编造 `d04=3` 的假轨迹并通过比对 |

## 结论

1. **GLM-4.6V 的视觉感知层对这种证据形式不可靠**：逐张分级会顺从"应有轨迹"编造数值（静止对照给了完美的 rise-fall 分级），不能作为"有没有动、轨迹如何"的裁决者。
2. **语义层可用**：正样本盲描述"向右侧摆动后回正"与真实语义吻合；乱序负样本被边界比对以"变化部位与全身躯干不吻合"正确拒绝——文本层推理与比对是可靠的。
3. **正负控制样本再次证明不可省略**（AC-ACC-02）：没有静止对照，第一轮的"全部连贯"会被误读为可用。

## 采纳的架构结论（与 F5 三级评估一致）

- **存在性、轨迹、幅度、复位由本地像素指标硬性判定**（确定性，已具备），模型结果只在本地指标确认存在动作时才被采信——静止幻觉被本地门控短路。
- **模型只承担两件事**：盲语义描述（变化部位 + 像什么动作）与"盲描述 vs 语义边界"的纯文本比对。
- 该架构下三样本全部判对：static 被本地短路、shuffled 被比对拒绝、ordered 通过。
- 若需更强的视觉 grounding，后续可测评 Qwen3-VL（本地开源）与豆包原生视频输入（原生时序编码），与本轮 GLM-4.6V 结论对照。

- `scripts/live2d-probe/review_motion_strip.cjs`：GLM 结构化评审（逐张分级 → 盲描述 → 纯文本边界比对，两段调用）。
