## 1. 画布与构图

- 画布：4096×4096，透明背景，正面中性站姿。
- 角色主体占画布高度约 85%，顶部发饰、两侧发尾、裙摆和挂件保留运动余量。
- 中心线垂直贯穿鼻梁、胸口、腰部；默认重心略稳定于双脚中间，不预设走路姿态。
- 首版不画复杂手势；双手使用可被后续肩臂/手通道替换的中性下垂姿态。
- 公开官方视觉只作人工设计参考；任何绘稿必须重新创作，不导入官方媒体、旧模型或其可识别局部。当前范围仅限项目所有者批准的私有研发，不得公开发布、商业化或分发。

## 2. 识别点清单（Stage 1 验收）

| 区域 | 必须出现 | 动态预留 |
|---|---|---|
| 头脸 | 符玄特征脸型、眼眉口、脸部阴影 | 头 XYZ、眨眼、眼球、眉嘴表情 |
| 发型 | 长发主轮廓、前发/侧发/后发边界 | 头发分束、发尾低幅物理 |
| 发饰 | 头顶主发饰、侧向挂件及连接点 | 发饰独立轻摆、遮罩关系稳定 |
| 上身 | 领口、肩线、上衣主色层次 | 呼吸、身体 XYZ、肩臂预留 |
| 袖口/手臂 | 左右袖口与手臂轮廓完整 | 单臂通道、袖口跟随 |
| 腰裙 | 腰部连接、裙摆前后层、下摆装饰 | 裙摆低幅物理、重心微动 |
| 下身 | 腿部和鞋可见且不被裙摆错误遮挡 | 走路/腿部后续扩展槽 |

**人工门槛**：缩略图、正面中性姿势和灰度轮廓均应不依赖文字标签即可识别为符玄；服饰不得以占位块交付。

## 3. 分层与绘制顺序

从后到前建议顺序：

1. 后景透明区域与角色边界备用层（不导出背景）；
2. 后发、后侧挂件、后裙摆；
3. 后腿、鞋后层；
4. 身体/颈部/肩部；
5. 上衣、领口、腰部；
6. 裙摆前层、下摆装饰；
7. 左右袖子、手臂、手；
8. 脸、耳侧发、前发；
9. 眼白、瞳孔、眉毛、嘴、脸部阴影；
10. 前发饰、胸前挂件、前侧丝带；
11. 高光、独立表情装饰和后续特效插槽。

所有会移动的边界必须在相邻层补足隐藏区域。每层命名需包含 `part_side_depth_role`，例如 `hair_front_L_motion`、`skirt_back_R_physics`；最终命名表在导入绘稿后更新。

## 4. 遮挡规则

- 前发遮脸，但眼睛、眉毛和嘴必须有独立可见区域；闭眼/张嘴不得露透明洞。
- 袖子/手臂与上衣、裙摆采用独立遮罩，抬臂时袖内和腋下留补画区域。
- 前裙摆遮腿上缘，裙摆运动时不穿过身体主体；腿和鞋的被遮挡区域必须补齐。
- 发饰、挂件与头发分离，挂件不得因头部转动穿入脸或肩。
- 物理候选层不得直接参与 LLM 逐帧控制，只接受内部物理输入。

## 5. 表情目标（首版）

首版只冻结表现目标，不宣称参数已实现：中性、轻微微笑、惊讶/警觉、困倦、委屈、张嘴、闭眼。每个目标需能从中性进入、保持、回中，且不得覆盖高优先级用户交互。
